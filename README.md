# Pourfecto.jl

**Pourfecto.jl** is a Julia package for planning and scheduling automated liquid handling workflows.

---

## ⚠️ This repository has moved

Pourfecto now lives inside the **CHESS** monorepo. This standalone repository is a stale historical record and is no longer developed or maintained.

👉 **Development, installation instructions, and documentation are here: [github.com/jensenlab/CHESS](https://github.com/jensenlab/CHESS)**

Please file issues, open pull requests, and install Pourfecto from that location going forward.
